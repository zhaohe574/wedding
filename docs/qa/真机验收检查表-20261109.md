## 使用说明

**前置条件**（不满足先补齐，否则结果不可信）
- 同一台**真机**（不是开发者工具模拟器），至少覆盖一台带安全区/Home 指示条的机型

- 至少两条动态：**一条带封面图**、**一条纯文字无封面**（A/B 组的关键对照）
- 微信支付可用（B 组付费票场景）

- `- [ ]` 未验（本表初始状态全部如此）

**口径纪律**：静态全绿（eslint / vue-tsc / 四道门禁 / build）只证明结构与产物，**不证明视觉与交互**。本表所有项在真机打勾前一律标「未验证」，报告里不要写「视觉已修复」。

## G. 请求重试（4 场景 · 关联 `d5e80961`）

> `isRetryableError` = `statusCode === undefined || >= 500`；`shouldRetry` 对 GET 默认 `retry=2`，即**总共最多 3 次请求（首次 + 2 次重试）**。

- [ ] **G1 · P0** 业务错误（HTTP 200 + code≠1，如「档期已被锁定」）→ **只发 1 次请求**，无重试、无重复 loading
- [ ] **G2 · P1** 断网 → 网络层错误（无 statusCode）→ 共 **3 次请求**后失败提示
- [ ] **G3 · P1** 服务端 5xx → 共 **3 次请求**后失败提示
- [ ] **G4 · P0** 真 403（未授权/Token 失效）→ **只发 1 次请求**，不重试、正确跳登录或刷新登录态

> 观察方式：开发者工具 Network 或抓包数请求次数；不要只看页面有没有转圈。
