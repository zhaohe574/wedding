## 一、长期工程红线（摘要）

完整规则见根目录 [AGENTS.md](../AGENTS.md)，核心口径如下：

1. **目录边界**：`uniapp/` 为已冻结旧包，禁止新增或常规修改；小程序所有开发统一落在 `newuniapp/`。
2. **前后台同步**：调整 `newuniapp/` 装修可配置区域（首页 hero、开屏、数据条、四宫格、服务承诺、弹窗广告、个人中心婚期卡/快捷入口）时，必须同步 `shared/contracts/decorate.ts`、后台整页镜像预览（`home-preview.vue` / `splash-preview.vue` / `user-preview.vue`）及对应 `widgets/<widget>/{options.ts,attr.vue,content.vue}`。
3. **设计令牌与品牌入口**：设计 Token 唯一源为 `newuniapp/src/styles/tokens.css`；品牌名称/图标唯一读取入口为 `newuniapp/src/composables/useBrand.ts`（禁止页面直引常量或自读配置）。
4. **金额与状态机**：金额只认服务端 `quote` 与订单字段，前端不做加减；订单动作只认服务端 `actions` / `action_reasons`；尾款 `balance` 不按钱包余额处理。
5. **数据库双向同步**：表结构与后台菜单/权限变动需同步维护安装基线 `server/public/install/db/like.sql`、`server/database/migrations/` 与 `server/database/menu/menu_manifest.php`。
