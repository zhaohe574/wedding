# 核心状态机

## 新人问卷任务

| 状态值 | 状态 | 允许流转 |
| --- | --- | --- |
| 0 | 待提交 | 1 已提交，2 已取消，3 已查看，4 已过期 |
| 3 | 已查看 | 1 已提交，2 已取消，4 已过期 |
| 1 | 已提交 | 终态 |
| 2 | 已取消 | 终态 |
| 4 | 已过期 | 终态 |

已提交任务重复提交可幂等返回成功但不得覆盖历史答案。已取消或已过期任务不可填写，接口需要返回明确失败原因。

问卷模板兼容策略：任务创建时冻结问卷版本和题目快照，提交时使用任务上的题目快照清洗答案并再次保存到答案记录；发布新版本不得改写已创建任务的版本快照。

过期与撤回能力：当前系统以 `STATUS_EXPIRED` 表示已过期，以 `STATUS_CANCELLED` 表示撤回或取消问卷任务；如果后续增加独立撤回接口，必须同步更新模型、OpenAPI、状态机和验收脚本。
