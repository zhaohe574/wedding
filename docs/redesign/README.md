## 3. 整体视觉方向（摘要，完整版见 `01` §1–§8）

**素笺契约 / Quiet Ledger** —— 把浪漫留给照片，把秩序留给界面：用纸感暖白、明确边界与可读的文字层级，让每一次档期确认与金额核对都像签一份看得清的文书。

五个关键词：**纸感 / 边界清晰 / 层级可读 / 金色克制 / 状态可信**。

三条不可违背原则：
1. 金色只做标点不做句子（单屏面积 ≤2%，禁作正文 / 控件边界 / 文字色）；
2. 任何信息不得单一编码（状态 = 语义色 + 形状 + 中文词；层级 = 字重 + 字号 + 留白至少两项；控件 = ≥3:1 边界 + 88rpx 热区 + 按下态）；
3. 可读性优先于装饰（中文 ≥12px、正文 ≥4.5:1、非文字控件边界 ≥3:1，冲突时删装饰）。

| 维度 | 统一后的规范 |
|---|---|
| 色彩 | 暖白 `#f8f6f0` / 深墨 `#181614` / 香槟金 `#c6a15b` 三色关系不变；新增 6 个 `--c-{tone}-border` 同色调描边；`--c-ink-3 → #6b655c`、`--c-neutral → #605a51`；正文全部 ≥4.5:1、`--c-control-border` 3.83:1；`--c-brand` 作文字 2.25:1 与白字压金 2.43:1 明令禁止 |
| 字体 | 6 档字号（`--fs-xs 24 / md 28 / lg 32 / xl 38 / 2xl 48 / number 64` rpx，**无 `sm`、有 `2xl`**）；字重 **400 / 500 / 600** 三档，禁 700/800/900；行高由 5 档收敛为 4 档；320px 兜底 `--fs-xs: max(24rpx,12px)`、`--fs-md: max(28rpx,14px)`（375px 及以上取值不变） |
| 间距 / 圆角 / 线 | 组内 16 / 组间 32 / 区块 96rpx，页面安全边距 32rpx；5 档圆角，卡片统一回 `--r-md 20rpx`；`--c-line`（纸的折痕，装饰）与 `--c-control-border`（控件轮廓）严格分界，1rpx 虚线仅限占位；卡片描边分层、阴影只给浮层 |
| 图标 | 6 档尺寸、`u-icon` iconfont 单一来源，本轮不引 SVG；清理 6 张零引用 tabbar PNG；按语义命名表覆盖首页 / 订单 / 消息 / 我的 / 查档期 / 人员 / 预约 / 支付 / 售后 / 日历 / 状态反馈 |
| 组件 | 15 类可视规格（导航栏、tabBar、按钮 5 变体 × 3 尺寸 × 4 状态、卡片、状态标签、表单、筛选 chip、区块标题、金额、骨架、空/错/结果页、Toast、加载更多、弹层抽屉、步骤条/日历状态点），状态一律三重编码 |
| 反馈 | 骨架屏用于首屏、遮罩用于提交/支付；「可重试 / 可恢复 / 不可重试」三态判定；30 行状态矩阵；约 40 个 `FB.*` 文案常量收敛；失败不替用户下结论、不伪装空态、不暴露 HTTP 码 |
| 动效 / 明暗 | 3 档时长 150/240/360ms，按下态 0.72–0.85 opacity 禁 scale；明确不做暗黑模式、不做运行时主题下发 |
