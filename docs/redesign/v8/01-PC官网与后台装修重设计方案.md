# PC 官网与后台装修重设计方案（v8.1 高定暖墨黑三屏升级完整记录）

> 范围：`pc/pages/index.vue`（PC 官网前台）、`admin/src/views/decoration/pc.vue`（概览）、`admin/src/views/decoration/pc_details.vue`（编辑台）、`admin/src/views/decoration/component/preview/pc-preview.vue`（流式预览）、`admin/src/views/decoration/component/widgets/pc-*`（Batch 3A 已完工，本文只描述不动）。
> 契约：`shared/contracts/pc-decorate.ts` ＋ `server/app/common/service/PcDecorateService.php`（两侧逐字同步）。
> 严禁改动：`uniapp/`（旧包冻结）、`shared/contracts/generated/**`（脚本生成文件）。
> 版本：v8 为「温润象牙白 + 墨黑点缀 · 4 模块」首版；**v8.1 升级为「高定暖墨黑 + 哑光香槟金 · 3 模块」**，本文为 v8.1 最终态完整记录。

## 1. v8 → v8.1 升级要点

1. **模块收敛 4 → 3**：`pc-about`（品牌理念）、`pc-stats`（数据背书）并入首屏或废弃，最终固定为 `pc-hero / pc-gallery / pc-miniprogram` 三屏，与参考图 1:1 对应。
2. **视觉升级**：从「温润象牙白 + 墨黑点缀」升级为「暖墨黑高定影院风 + 哑光香槟金」，PC 前台、后台预览、后台概览页与编辑台四端气质统一。
3. **系统配置零配置复用**：站点 Logo、品牌名、渠道小程序码、备案信息全部自动复用系统配置，装修字段留空即可，不重复维护。
4. **后台双页同步翻新**：概览页 `pc.vue` 与编辑台 `pc_details.vue` 同步为暖墨黑高定风格，模块文案与 3 模块架构对齐。

## 3. 3 模块最终架构与参考图 1:1 结构对照

**契约**：`PC_WIDGET_ORDER = ['pc-hero', 'pc-gallery', 'pc-miniprogram']`，顺序固定、不可增删排序；前台 `pc/pages/index.vue` 与后台 `pc-preview.vue` 逐区一比一镜像。

| 参考图区域 | 契约模块 | 结构对照（前台 = 后台预览） |
| :--- | :--- | :--- |
| 影院级全幅首屏 | `pc-hero`（01 电影感首屏） | 全幅主视觉大片 + 暗部渐晕；左下衬线多行主标题（`title` 内 `\n` 折行）+ 英文眉题 `eyebrow`；右下角扫码浮卡（`qrcode` 图 + `qr_caption`） |
| 高定画册跨页 | `pc-gallery`（02 精选现场） | 眉题 `02 / SELECTED SCENES` + 衬线标题；非对称 1+2 版式：1 张竖幅主图（SCENE 01）+ 右侧 2 张叠放（SCENE 02 / 03），图注含英文场景编号、中文标题与一句话描述 |
| 小程序引导收尾 | `pc-miniprogram`（03 小程序引导） | 深墨渐变大卡：左侧衬线主标题 + 三项双语体验亮点（`title` + `en_label`）；中部双手机实景样机；底部底座扫码区（二维码 + `qrcode_caption` + `miniapp_name` + 联络信息），页脚并入品牌方印 + `footer_slogan` + 用户协议 / 隐私政策 / 备案提示 |

- 顶部双语极简导航：Logo（缺失回退品牌方印）+ `brand_en` / 品牌名 + 仅展示已启用模块的锚点（CEREMONY HOUSE / PORTFOLIO / MINI PROGRAM）+ 深墨「进入小程序」按钮；锚点随模块隐藏联动消失。
- 模块 `content.enabled = 0` 时前台整块不渲染（含导航锚点），后台预览覆盖「该模块已隐藏，前台不渲染」遮罩。
- 已知差异（预览仅镜像）：字体回落系统栈不做 webfont、悬停动效与粘性导航毛玻璃不做、预览内点击不跳转不弹扫码弹窗。

## 4. 系统配置复用策略（装修字段留空即自动复用）

| 复用项 | 来源 | 缺省回退 | 复用位置 |
| :--- | :--- | :--- | :--- |
| 站点 Logo | `website.pc_logo`（前台 `PcLogic` 同步暴露 `pc_logo` / `shop_logo`；后台经 `getDecoratePc().pc_logo` 下发） | 品牌方印：品牌名首字 + 香槟金衬线方印（`navBrandName = content.brand_name || brand_name`，方印取首字） | 导航条 / 页脚品牌区 / 后台概览「系统复用状态」卡 |
| 品牌名 | `website.shop_name`（`getDecoratePc().brand_name`） | 契约默认 `格林社` | 导航品牌区、模块内容缺省、概览页方印兜底字 |
| 渠道小程序码 | `mnp_setting.qr_code`（`DecorateDataLogic::pc()` 下发为 `mnp_qr_code`） | 模块 `content.qrcode` 优先，留空回退 `mnp_qr_code` | **三处统一复用**：首屏右下扫码浮卡、第三屏底座扫码区、后台概览「系统复用状态」卡 |
| 双手机样机 | `content.preview_image` 优先渲染 front 屏 | 留空时自动用首屏主图 / 现场图渲染温润象牙白微缩小程序界面（档期行、主持标签、现场头像全部自动生成） | `pc-miniprogram` 中部（后台预览镜像） |
| 备案与法务 | 系统备案配置（`copyright` config） | — | 页脚用户协议 / 隐私政策 / 备案提示，前台与预览一致 |

- 概览页「系统复用状态」卡明示两条状态：`渠道小程序码：已配置 / 待在渠道设置配置`、`站点 Logo：已配置 / 使用默认香槟金方印`（未配置时展示品牌方印兜底字示例），并注明「装修字段留空时自动复用系统配置」。
- PC 端定位保持不变：仅展示品牌与引导微信扫码进入小程序，不承载重型交易与表单，契约层禁止 `link / cta_link / more_link` 功能型跳转字段。

## 5. 历史 4/6 模块无损迁移规则

**决策链**：v7 及更早为 6 模块（`pc-banner` 首屏轮播 / `pc-about` 品牌理念 / `pc-advantages` 服务能力 / `pc-gallery` 案例图集 / `pc-stats` 数据背书 / `pc-contact` 联系信息）→ v8 收敛为 4 模块 → **v8.1 收敛为 3 模块**：数据背书并入首屏数据条后随 v8.1 重排取消（首屏改为扫码浮卡 + 全幅大片），品牌理念信息并入首屏文案与精选现场描述，联系信息并入小程序引导卡，全部功能型跳转字段废弃。

**迁移映射**（实现见 `parsePcDecorateWidgets`，与 `PcDecorateService.php` 逐字一致；`pc-about` / `pc-advantages` / `pc-stats` 的内容随收敛不再输出，`pc-banner` / `pc-contact` 保留如下无损迁移）：

| 旧模块 / 旧字段 | 新去处 | 规则 |
| :--- | :--- | :--- |
| `pc-banner.content.data[0].image` | `pc-hero.image` | 仅当不存在 `pc-hero` 模块时回填轮播首图；文案走默认值 |
| `pc-stats.content.data` | — | `{ value, label }` 数据并入首屏数据条后随 v8.1 三屏重排取消独立承接，原字段不再迁移输出 |
| `pc-advantages.content.data` / `pc-about.content` | — | `{ kicker, title, description }` 服务能力与品牌理念并入首屏文案与精选现场描述，原字段不再迁移输出 |
| `pc-contact.phone / service_time / footer_slogan` | `pc-miniprogram` 同名字段 | 仅当不存在 `pc-miniprogram` 模块时迁移，非空字符串覆盖 |
| `pc-contact.address` | `pc-miniprogram.address` | 占位文案「请在后台装修中填写企业地址」视为未填写，转空串 |
| `pc-contact.qrcode` | `pc-miniprogram.qrcode` | 等于旧默认客服二维码 `/resource/image/adminapi/default/kefu01.png` 时视为占位，不迁入 |
| `link / cta_link / more_link` 等跳转字段 | —（废弃） | 契约归一化时丢弃，不写回数据库 |
| 兼容形态 | — | JSON 字符串、PHP `json_encode` 数字键对象（`{0:..}`）一律宽松还原；解析永不抛异常，恒输出 3 个固定模块 |
