# 可约人员列表页 UI 方案（v4 · 两列人像网格）

> 页面：查档期 →「查看 N 位可约人员」后的结果页
> 目标屏宽：320 / 375 / 390，≥600 居中
> 设计语言：沿用 `newuniapp` 现有令牌（暖白纸感、墨黑字、香槟金点缀、无阴影）

---

## 0. 页面定位

### 0.1 这一页要回答什么

用户在上一页已经选好**日期 + 地区 + 类型**，进入本页只做一件事：

> 这天有哪几位老师有空？谁看起来更适合我的婚礼？

所以本页的核心不是「筛选」，而是**认人**。人像必须是第一视觉，文字只做确认与补充。

### 0.2 设计目标

| 目标 | 具体表现 |
|---|---|
| 3 秒扫到脸 | 首屏至少完整露出 2×2 四张人像卡；人像占卡片面积 ≥65% |
| 一眼看到可约 | 姓名右侧固定显示可约状态，颜色 + 圆点 + 文字三重编码 |
| 不像电商商品卡 | 不用价格做主视觉、不用红黄促销标、不用阴影浮层 |
| 条件不在本页改 | 顶部只读上下文 + 排序；改条件回查档期页（条件唯一真源） |

### 0.3 非目标

- 不在卡片上做收藏、咨询、对比、加购；
- 不在本页编辑日期/地区/类型；
- 不展示完整简介、作品集、套餐明细（这些属于详情页）。

## 1. 布局

### 1.1 页面结构

```
┌──────────────────────────────────┐
│ ‹            可约人员             │  导航栏 88rpx
├──────────────────────────────────┤
│ 11月11日 周三 · 杭州·西湖区  改条件 ›│  上下文条 112rpx（吸顶）
│ 6 位可约              推荐排序 ▾  │
├──────────────────────────────────┤
│ ┌───────────┐  ┌───────────┐     │
│ │           │  │           │     │
│ │  3:4 人像  │  │  3:4 人像  │     │  网格：2 列
│ │           │  │           │     │  页边距 30rpx
│ │           │  │           │     │  列间距 24rpx
│ ├───────────┤  ├───────────┤     │  行间距 24rpx
│ │林昭    ●可约│  │沈知夏  ●可约│     │
│ │主持人·8年 ¥3,800│ │主持人·6年 ¥4,200│ │
│ │大气稳重，擅长中式…│ │温柔细腻，西式草坪…│ │
│ └───────────┘  └───────────┘     │
│ ┌───────────┐  ┌───────────┐     │
│ │    …      │  │    …      │     │
│ └───────────┘  └───────────┘     │
│           已加载全部 · 共 6 位      │
└──────────────────────────────────┘
```

自上而下只有三段：**导航 → 上下文条 → 网格**。没有 Hero 大标题、没有轮播、没有运营位。

### 1.2 顶部标题区

| 元素 | 位置 | 高度 | 内容 | 说明 |
|---|---|---|---|---|
| 导航栏 | 固定顶部 | 88rpx | `‹` + 「可约人员」 | 标题 34rpx / 600 / ink，居中；返回 56×56rpx 热区 |
| 上下文条 | 导航下方，吸顶 | 112rpx | 两行，见下 | surface 底 + 底部 1rpx line；滚动时只这一条吸顶 |
| 第一行 | 上下文条上部 | 48rpx | `11月11日 周三 · 杭州·西湖区` + 右侧 `改条件 ›` | 日期与地区 21rpx / ink-3；`改条件` 21rpx / brand-text |
| 第二行 | 上下文条下部 | 56rpx | `6 位可约` + 右侧 `推荐排序 ▾` | 数字用 serif 33rpx；排序是 56rpx 高的胶囊 chip |

**为什么标题不放大**：标题只有四个字，做成 48rpx 的 Hero 会白白吃掉 60–80rpx，首屏就少露一截人像。导航标题 + 上下文条合计 200rpx（≈104px），加网格上边距后第一排人像从约 112px 处开始，占 844px 屏高的 13%。

**上下文条的两种形态**

| 入口 | 第一行 | 第二行 |
|---|---|---|
| 从查档期进入（主路径） | 日期 · 地区 · 类型，只读 | `N 位可约` + 排序 |
| 全量人员入口 | 日期 / 类型 / 排序 三枚筛选 chip，可横滑 | `N 位` 计数，右对齐 |

两种形态同高（112rpx），切换入口不改变网格起始位置。

**占位与吸顶规则**

- 上下文条始终占位，不因滚动隐藏；滚动后导航栏底部出现 1rpx line，上下文条保持 surface 底。
- 不在列表上方再加「筛选」行；排序是唯一可交互项。
- 回到本页（从详情返回）时保持滚动位置，上下文条不重新动画。

### 1.3 两列网格

**网格定义**

- 列数：**固定 2 列**，不做 3 列断点。
- 对齐：两列等宽，左列左对齐页边距，右列右对齐页边距。
- 卡片顺序：按行优先（左 → 右 → 下一行），保证视线 Z 字扫描。
- 卡片等高：同一行两张卡高度一致（信息区固定最小高度，简介固定 2 行）。

**间距表（rpx 为设计值，px 为对应屏宽实际值）**

| 屏宽 | 页边距 | 列间距 | 行间距 | 单卡宽 | 人像高（3:4） | 信息区高 | 单卡总高 |
|---|---|---|---|---|---|---|---|
| 320 | 24rpx ≈10px | 20rpx ≈9px | 24rpx ≈10px | 341rpx ≈146px | ≈194px | ≈90px | ≈284px |
| 375 | 30rpx =15px | 24rpx =12px | 24rpx =12px | 333rpx ≈167px | ≈222px | ≈101px | ≈323px |
| 390 | 30rpx ≈16px | 24rpx ≈12px | 24rpx ≈12px | 333rpx ≈173px | ≈231px | ≈102px | ≈333px |
| ≥600 | 30rpx ≈24px | 24rpx ≈19px | 32rpx ≈26px | 266px（容器 600px） | ≈355px | ≈110px | ≈465px |

**计算口径**：`单卡宽 =（屏宽 − 2×页边距 − 列间距）÷ 2`；`人像高 = 单卡宽 × 4 ÷ 3`。

**首屏容量**

- 390×844（应用可视高 800，不含系统状态栏）：导航 44 + 上下文 58 + 网格上边距 10 + 两行卡 666 + 行间距 12 ≈ 790px，**2×2 四张卡完整可见**，余 10px；「已加载全部」在首屏下沿之外，轻微下滑即可看到。
- 375×812（应用可视高 768）：两行卡 646 + 头部 102 + 网格上边距 10 + 行间距 12 ≈ 770px，四张卡下沿基本贴住屏幕下沿，底部提示需下滑。
- 320×640：第一行两张完整、第二行露出人像上半部分，形成明确的下滑暗示。

### 1.4 不同屏宽的适配

| 屏宽 | 策略 |
|---|---|
| 320–359 | 仍为 2 列；页边距降到 24rpx，列间距 20rpx；姓名 31rpx，状态 18rpx，简介 20rpx；简介仍 2 行，字号缩小不截断行数 |
| 360–430 | 标准值（30/24/24rpx），不缩放 |
| 431–599 | 沿用标准值，卡片随屏宽变宽；单卡最大 266px（即 600px 容器下的列宽），接近 600px 时不再变宽 |
| ≥600 | 全局 600px 容器居中；仍 2 列；行间距加到 32rpx；不做 3 列、不做平板双栏 |
| 横屏 | 不改变列数；若高度 <500px，隐藏上下文条第一行，只保留计数与排序 |

**安全区**

- 网格底部 padding：48rpx + `env(safe-area-inset-bottom)`。
- 最后一排卡片不被 tabbar 遮挡（本页无 tabbar，只有导航返回）。
- 滚动条不占列宽；两列都按页边距对齐，不额外缩进。

## 2. 视觉

### 2.1 整体风格取向

**「一叠相纸」**：暖白底、无阴影、细描边，每张卡像一张 3:4 的相纸，信息像相纸下方的铅笔标注。

| 维度 | 决策 |
|---|---|
| 底色 | `--c-bg #FAF6EE`，比卡片更深半阶，让卡片浮起来但不靠阴影 |
| 卡片 | `--c-surface #FFFDF8`，1rpx `--c-line` 描边，28rpx 圆角 |
| 主文字 | `--c-ink #181614` |
| 次文字 | `--c-ink-2 #5A554E` / `--c-ink-3 #6B655C` |
| 品牌金 | `--c-brand #C6A15B`，只用于推荐标、价格符号、极少量分隔；不做金色块 |
| 状态色 | 可约 `--c-success #48644B`，紧张 `--c-warning #8A5A16`；红色不用于档期 |
| 阴影 | **无**。卡片分隔只靠描边 + 间距 |
| 渐变 | **无**。图片上不加黑色渐变遮罩（会破坏暖白纸感） |

### 2.2 人像图规格

#### 比例与裁切

- 比例：**3:4（宽:高）**，全部卡片统一，不因原图比例变化。
- 裁切方式：等比填充（cover），焦点默认 **50% / 38%**（水平居中、垂直偏上）。
- 构图要求：头顶留白 8–12%，下巴以下保留肩线；不裁掉头顶、耳朵、下巴。
- 人像占画面比例：半身（胸口以上），脸部高度约占画面 22–28%。
- 眼睛位置：落在画面上 1/3 线附近（约 33–40%）。

#### 图片规格

| 项 | 要求 |
|---|---|
| 最小尺寸 | 900×1200px（对应 390 屏 2x 的 346×461，留 2.6 倍余量） |
| 推荐尺寸 | 1200×1600px |
| 格式 | JPEG / WebP，sRGB |
| 单张体积 | ≤500KB（列表首屏 4 张 ≤2MB） |
| 背景 | 暖中性（米、灰、浅木色），避免纯白与高饱和 |
| 光线 | 柔光正面或 45° 侧光；避免强逆光、硬阴影 |
| 内容 | 单人、正视或微侧、自然表情；不出现文字、水印、多人合影 |
| 服装 | 与品牌调性一致的西装/礼服/衬衫；避免大面积荧光色 |

#### 裁切兜底

- 原图比例偏差 >8%：上传时进入裁剪器，默认框 3:4，允许上下拖动焦点。
- 人脸检测失败：允许手动把焦点拖到脸部；保存焦点坐标（百分比），列表按该焦点裁切。
- 横图：强制进入裁剪器，不直接拉伸。
- 低分辨率：<600×800 时提示「建议更换更清晰的照片」，仍允许使用但列表标注不做放大。

#### 展示细节

- 图片容器先占位（surface-2），图片加载完成后 200ms 淡入，避免布局跳动。
- 浅色衣服/浅背景：图片容器内侧加 1rpx `rgba(24,22,20,.06)` 内描边，防止人像与卡片融在一起。
- 图片上不加圆角遮罩，只跟随卡片顶部圆角裁切。

### 2.3 人像下方的信息层级

信息区固定 3 个视觉行（5 个字段），行高与间距固定，保证同一行卡片等高。

| 顺序 | 字段 | 字号 / 字重 / 颜色 | 对齐 | 规则 |
|---|---|---|---|---|
| 1 | **姓名** | 33rpx / 600 / ink | 左 | 最长 6 字，超出省略；英文名用 29rpx |
| 2 | **可约状态** | 20rpx / 500 / success 或 warning | 姓名右侧，右对齐 | `● 可约` / `● 仅 1 档`；圆点 8rpx；不占独立行 |
| 3 | **身份 · 年限** | 21rpx / 400 / ink-3 | 左 | `主持人 · 8 年`；无年限时只显示身份 |
| 4 | **价格（可选）** | 25rpx serif / ink；`起` 18rpx ink-3 | 身份右侧，右对齐 | 只有 `has_price` 时显示；无报价不占位 |
| 5 | **一句话简介** | 22rpx / 400 / ink-2 | 左 | 固定 2 行，超出省略；无简介时用擅长风格的纯文本兜底，不换成标签 |

**主次关系**

1. **姓名**是文字层的第一主视觉，字号最大、颜色最深；
2. **人像**是整张卡的第一主视觉，优先级高于姓名；
3. **可约状态**是决策信息，必须与姓名同一视线高度，但不能比姓名更重（所以用小字 + 圆点，不用实心标签）；
4. **身份/年限**回答「他是做什么的、靠不靠谱」；
5. **简介**回答「他的风格适不适合我」，是最后一行，允许被截断；
6. **价格**是辅助决策，放在身份行右侧，不单独占一行。

**为什么卡片不放风格标签**

本页已经带着类型/风格条件进来，标签是「筛选语言」；卡片应该回答「这个人是什么感觉」，所以选一句话简介而不是 2–3 枚 tag。标签、作品、完整履历留在详情页。这样两列宽度下不会出现「标签换行 → 卡片高度不齐」的问题。

**为什么状态不进图片**

图片上只允许一个「推荐」标（左上，9 字以内）。可约状态如果压在图片上，会和浅色背景/浅色服装打架；放在姓名右侧，白底黑字最稳，也符合「文字回答状态、图片负责人」的分工。

### 2.4 卡片与视觉分隔

| 项 | 规格 |
|---|---|
| 卡片圆角 | 28rpx（图片顶部同圆角，信息区底部同圆角） |
| 描边 | 1rpx `--c-line`，无阴影 |
| 图片与信息区 | 不加分割线；信息区上 padding 18rpx，靠留白分隔 |
| 卡片之间 | 列间距 24rpx、行间距 24rpx；**间距就是分隔**，不加额外投影或底色块 |
| 推荐标 | 图片左上角，`推荐` 18rpx / brand-text，底色 `rgba(255,253,248,.92)`，圆角 8rpx，padding 4rpx 10rpx |
| 按压反馈 | `scale(.985)` + `opacity(.92)`，120ms ease-out；松手 160ms 回弹；不做阴影抬升 |
| 选中/浏览过 | 不做「已查看」灰化，避免列表越滑越脏 |

### 2.5 色彩与字体纪律

- 一屏颜色不超过 3 类：墨色（文字）、金色（推荐/价格符号）、状态色（绿/琥珀）。
- 金色面积 <5%；不使用金色描边卡片、金色渐变按钮。
- 姓名 sans 600；价格与数字用 `--font-serif`；其余 sans。
- 正文字号不低于 20rpx（10px），320 屏下简介不低于 20rpx。

## 3. 交互

### 3.1 点击卡片

| 项 | 规则 |
|---|---|
| 热区 | 整张卡片，包含图片与信息区；最小 88rpx |
| 按下 | 120ms 内缩到 98.5%，透明度 92% |
| 松手 | 160ms 回弹；同时触发跳转，不等动画结束 |
| 跳转 | 人员详情页，携带 `staff_id`、`date`、省市区、`category_id`、`from=query` |
| 返回 | 恢复列表滚动位置、排序、已加载页数；不重新请求首屏、不闪骨架 |
| 连点 | 300ms 内只响应一次，避免开两个详情页 |
| 卡片内其他可点区 | 无。收藏/咨询/看作品集都在详情页 |

### 3.2 排序

- 点 `推荐排序 ▾` → 底部 sheet：推荐 / 评分优先 / 价格从低到高 / 从业年限。
- 选中即生效：列表回到顶部、显示骨架（保留上下文条）、重新请求第一页。
- 排序不属于筛选条件，不回写查档期页；返回查档期再进来时重置为「推荐」。
- sheet 高度 ≤40% 屏高，选中项左侧带 check，点击即关闭。

### 3.3 改条件

- 点 `改条件 ›` → 返回查档期页（`navigateBack`），不新开页面。
- 查档期页保留用户原来的日期/地区/类型；改完再进来重新请求。
- 本页不提供日期/地区/类型的任何编辑入口，避免出现两套条件真源。

### 3.4 加载态

| 场景 | 表现 |
|---|---|
| 首屏加载 | 4 张骨架卡（2×2），图片块与人像 3:4 同高、整卡与真实卡等高；图片块 surface-2 + 1.2s shimmer；文字 3 行（60% / 40% / 85%）；不使用整页 spinner |
| 切换排序 | 保留上下文条，网格整体淡出到 40% 后替换为骨架；不整页白屏 |
| 分页加载 | 底部追加 2 张骨架卡，已有卡片不动；不显示「加载中…」文字 |
| 加载完成 | 底部一行 `已加载全部 · 共 6 位`，20rpx / ink-3，居中 |
| 图片加载 | 容器先占位；图片加载完成 200ms 淡入；失败走 3.6 |
| 下拉刷新 | 顶部出现 48rpx 金色进度条，列表不清空；完成后 1s 内收起 |

### 3.5 空态

| 类型 | 触发 | 文案 | 动作 |
|---|---|---|---|
| 条件内无结果 | 有筛选条件，结果为 0 | 标题「这天暂时没有可约人员」；说明「换个日期或放宽风格试试」 | 主按钮「看相邻可约日」；文字链「改条件」 |
| 全站无人员 | 无任何可约人员 | 标题「暂时还没有可约人员」；说明「稍后再来看看」 | 不给重试（不是错误），可给「返回查档期」 |
| 空态布局 | — | 垂直居中偏上（距上下文条 180rpx），图标 120rpx，标题 33rpx，说明 22rpx | 不用整屏插画，不用大色块 |

### 3.6 图片加载失败 / 无照片

- **占位**：`--c-brand-bg` 暖米底 + 姓氏首字（serif 96rpx / brand-text），居中；底部居中 18rpx `暂无照片`（ink-3，60% 透明度）。
- 不使用灰色破图图标、不显示空白、不拉伸其他图片。
- 加载失败只自动重试 1 次；仍失败保持占位，不循环请求、不弹 toast。
- 占位块与人像同高（3:4），保证卡片高度不变。
- 姓氏首字取姓名第一个字；复姓取第一个字；英文名取首字母大写。

### 3.7 错误态

- 网络/超时/5xx：复用 `base-empty` 的 error 形态，标题「人员没加载出来」，按钮「重新加载」。
- 保留上下文条与排序，不清空条件、不回退页面。
- 部分图片失败不影响整页，只有单卡降级。
- 错误态不伪装成空态；可重试与不可重试要区分文案。

### 3.8 无障碍与手感

- 卡片 `aria-label`：`林昭，主持人，8 年经验，可约，3800 元起`。
- 图片 `alt` = 姓名；占位块 `aria-label` = `林昭，暂无照片`。
- 可约状态不只靠颜色：圆点 + 文字双编码。
- 点击热区 ≥88rpx；卡片间距 ≥20rpx，降低误触。
- 支持系统字体放大：姓名最多 2 行、简介最多 3 行，不裁切关键信息。
- `prefers-reduced-motion`：关闭缩放与淡入，只保留透明度切换。

## 5. 验收清单

- [ ] 320 / 375 / 390 / 600 下始终 2 列，不折行、不出现 3 列。

### 交互

- [ ] 整卡可点，按压有 98.5% 缩放反馈，300ms 防连点。
