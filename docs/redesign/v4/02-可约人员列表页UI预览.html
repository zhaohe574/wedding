SPEC

布局与视觉要点

网格

2 列 · 固定

页边距 30rpx，列间距 24rpx，行间距 24rpx。单卡宽 =（屏宽 − 2×页边距 − 列间距）÷ 2，390 下约 173px。

人像

3:4 宽 : 高

等比填充，焦点 50% / 38%；头顶留白 8–12%，保留肩线。最小 900×1200，单张 ≤500KB。

信息

5 项封顶

姓名 → 可约状态 → 身份·年限 → 简介（2 行）→ 价格（可选）。标签与完整履历留在详情页。

分隔

1rpx 描边

卡片无阴影、无渐变。靠 1rpx 描边与 24rpx 间距分隔；按压时 scale 98.5% + 透明度 92%。

为什么固定 2 列
这页的任务是「认人」，不是「逛商品」。3 列会把 390 下的单卡压到 110px 左右，脸部宽度不足 70px，人像就退化成缩略图。

为什么状态不压在图里
浅色礼服与浅色背景会让浮层状态失焦；放在姓名右侧，白底黑字最稳。图片上只留一个「推荐」标。

为什么卡片不放标签
本页已经带着类型/风格条件进来，标签是筛选语言；卡片应该回答「这个人是什么感觉」，所以用一句话简介，且固定 2 行，保证同行卡片等高。
预览使用项目内已有主持人素材，仅作版式示意；实际人像以 3:4、900×1200 以上为准。 UI 规划 v4 · 2026-11-10
