## 3. U1 阻断级缺陷：已修复（用户截图反馈）

**现象**：用户上传微信开发者工具截图，`pages/index/index` 首页变成纯文字/图片堆叠、卡片无边框圆角、颜色与间距全失、底部 tabBar 文字叠压。

**根因**（主理人独立定位）：本工程 uni-app 小程序端**未把任何全局 CSS 编译进 `app.wxss`**——`App.vue` 的 `<style>` 即便只写一行纯 CSS 也不进产物，`main.ts` 的 `import './styles/index.scss'` 同样不进；`dist/build/mp-weixin/app.wxss` 仅 **720 字节**（全为 uni-app 框架内置 `page{--status-bar-height...}`），全 dist 搜不到 `--c-bg:` / `--fs-xs:` 定义与 `#f8f6f0`，只有 `var(--c-*)` 消费点。因此 42 页所有颜色/字号/间距/圆角/状态色变量悬空。H5 产物含 `--c-bg:` 定义，故仅小程序端异常。

**修复**（`f1179f1a`，5 个文件）：
1. `newuniapp/vite.config.ts` 新增 `injectGlobalWxss()` 插件：`writeBundle` 阶段仅对 `mp-weixin` 把 `tokens.css`（SSOT）与 `globals.scss` 的 `sass` 编译结果注入 `app.wxss`（幂等，`--c-bg:` 已存在则跳过；编译失败回退读 `globals.css`）。
2. 从 `index.scss` 拆出 `src/styles/globals.scss`（全局规则），`index.scss` 改为 `@import './globals.scss';` 供 H5 复用，消除跨入口相对路径基准差异；`App.vue` 的 `<style>` 仅保留说明注释。
3. `src/styles/globals.css` 为 `globals.scss` 的编译产物（回退用）。

**验证**（构建产物 + 全门禁，均 exit 0）：
- `app.wxss` **720B → 8083B**，含 `--c-bg: #f8f6f0`、`--fs-xs: max(24rpx, 12px)`、`f8f6f0`、`page-wrap`、`chip-bar`、`is-pressed`、`ellipsis`、`tone-success` 全部变量与全局类。
- `redesign-ac-check.mjs` 63 文件违规 0 / `{}` 全绿；`redesign-zero-check.mjs` 116 文件违规 0 / `{}` 全绿；`type-check`、`pages:check`（42 页）、`check-feedback-consistency`、`build:mp-weixin:check`（主包 385.3KB）、`validate:dist` 全部通过。
- `npm run build:h5` exit 0，H5 产物 `assets/index-*.css` 仍含 `--c-bg:` 定义（无回归）；随后重建小程序产物，`app.wxss` 保持 8083B。
- 主链路业务文件、`STEPS`、`POLL_INTERVALS`、`shared/` 零 diff；未引入 npm 依赖；`newuniapp/` 工作区干净。

> 用户侧操作：微信开发者工具需**重新编译 / 刷新模拟器**以加载新的 `app.wxss`（dist 已更新）。
