05 320 窄屏元信息换行不截断；指示器与展开按钮不重叠。

配置 → 展示映射

所有高度、样式均由后台配置推导，页面内不写死日期或像素值
Mode
小图 / 大图
小图可展开；大图固定。切换只改高度与一个按钮，不改结构。
Height
280 – 960rpx
再叠加 58vh 视口上限，避免大屏上 800rpx 变成 800px。
Indicator
5 种形态
圆点 / 数字 / 进度条 / 长条 / 无，统一落在左下同一基线。
Long detail
图片块 + 文本块
图片全宽零间距；文本按 42rpx 栏宽；块间 32rpx。
后台配置取值展示形态约束 / 兜底
banner_mode1 / 2小图可展开 / 大图固定非 1/2 → 小图
banner_small_height200–800rpx小图初始舞台高度缺失 → 400；渲染下限 280rpx
banner_large_height≥300rpx展开高度 / 大图固定高度≤ small 时不出现展开；上限 960rpx + 58vh
banner_indicator_style0–4无 / 圆点 / 数字 / 进度条 / 长条非法 → 圆点；单张 → 隐藏
banner_autoplay0 / 1是否自动切换单张或视频页不自动翻页
banner_interval1000–10000ms切换节奏 / 进度条时长<1000 → 3000
long_detailJSON blocks图片块全宽无缝；文本块按样式渲染空 → 整段隐藏；非 JSON → 纯文本兜底
身份卡为什么上浮：400rpx 小图时，姓名压在图上会同时看不清脸和字。卡上对比度稳定，图片也能保留婚礼现场的高光。
长图为什么全宽：后台明确要求「首尾无间距」，加边距或圆角会露出接缝；文本块单独回到 42rpx 栏宽保证可读。
展开为什么手动：自动改变首屏高度会让用户正在看的内容跳走；运营要「大图第一眼」可直接配置大图模式。
数据缺口：v2 详情目前缺 long_detail 与 4 个轮播配置字段，落地前需补齐，否则只能回退 v1。
