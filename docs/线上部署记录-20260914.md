## 上线过程中补充修复

MySQL 5.7 不支持新表基线中的 `utf8mb4_0900_ai_ci`，迁移已改为使用兼容排序规则，并确保迁移异常返回非零退出码。该问题在维护期间处理完毕，重新迁移和表结构核对通过后才恢复访问。

自动调度观察发现，定时表达式库将整数时间戳按“当前时间”处理，导致任务不断推迟。现改为传入日期对象，扩充从完整调度入口触发的回归，确认到期任务确实执行、最后执行时间推进、未到期任务跳过。17:33 自动调度中所有到期任务执行成功，任务错误字段为空。
