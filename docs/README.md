# 婚庆服务预约系统

## 项目入口

- `server`：ThinkPHP 后端、安装器、服务号通知、微信支付和定时任务。
- `admin`：运营后台，负责 CRM、订单、活动、问卷、售后、结算、海报和内容管理。
- `uniapp`：微信小程序业务端，负责预约、订单、付款、履约、售后和服务人员工作台。
- `pc`：品牌、案例、资讯和联系展示，不承载登录、预约或支付。

## 业务边界

支付只支持微信小程序和线下收款；服务号只负责通知和关注绑定；验证码短信保留。订单尾款使用 `balance` 字段，不能按钱包余额处理。
