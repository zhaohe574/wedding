# 09 · 品牌动态配置（小程序名称 / 图标 / Slogan）

> 目标：小程序的**名称**与**图标**不再写死在前端，统一由后台「网站信息 → 前台设置」下发。
> 前端只保留一份「兜底值」，用于首次启动且请求失败的最坏情况。

---

## 1. 配置字段

后台路径：**设置 → 网站信息 → 前台设置**（`admin/src/views/setting/website/information.vue`）

| 后台表单项 | 存储位置 | 接口字段 | 前端映射 | 说明 |
| --- | --- | --- | --- | --- |
| 前台名称 | `config` 表 `website.shop_name` | `website.shop_name` | `BrandProfile.name` | 小程序名称，所有展示位的文案源 |
| 前台LOGO | `config` 表 `website.shop_logo` | `website.shop_logo` | `BrandProfile.logo` | 小程序图标，绝对 URL |
| 前台Slogan | `config` 表 `website.shop_slogan` | `website.shop_slogan` | `BrandProfile.slogan` | 副标题 / 英文锁定行，空则不渲染该行 |
| —（派生） | — | — | `BrandProfile.seal` | 名称首字，图标缺失/加载失败时的文字回退 |

接口：`GET /api/index/config`（`IndexController::config` → `IndexLogic::getConfigData()`），
`website` 节点即上表三项。`GET /api/v2/home` 的 `config` 节点复用同一份数据。

**后端归一化**（`server/app/api/logic/IndexLogic.php`）：

- `shop_name` 为空或等于模板默认值 `likeadmin` → 下发空串；
- `shop_logo` 为空或指向模板占位图 `resource/image/adminapi/default/` → 下发空串
  （避免把 likeadmin 的占位图标当成商家图标）；
- `shop_slogan` 去首尾空白。

这样前端只需按「空 = 未配置」处理，不用在前端判断什么是模板值。

---

## 2. 取值优先级

```
remote（本次接口）  →  cache（上次成功下发，同步读 storage）  →  fallback（constants/brand.ts）
```

逐字段独立回落：后台只填了名称、没传 LOGO 时，名称用 remote，图标继续用缓存/兜底，不会整块降级。

| 场景 | 表现 |
| --- | --- |
| 加载中（无缓存） | 直接渲染兜底名称 + 印章字，**不出现空白、骨架或 loading 闪烁** |
| 加载中（有缓存） | 直接渲染上次的名称/图标，配置回来后原地替换 |
| 配置缺失（字段为空） | 该字段走下一级；`slogan` 为空时整行不渲染（不留空行） |
| 请求失败 | 用缓存；无缓存用兜底；同时上报 `api_error`（`index.config`） |
| 图标 404 / 加载失败 | `brand-mark` 内部 `@error` 标记该 URL 失效 → 全站回退到名称首字印章 |

兜底常量只有一处：`newuniapp/src/constants/brand.ts` 的 `BRAND_FALLBACK`。

## 3. 加载时机与更新机制

| 时机 | 触发点 | 行为 |
| --- | --- | --- |
| 冷启动 | `App.vue onLaunch` → `appStore.getConfig()` | 拉 `/index/config`，成功即写品牌缓存 |
| 首页首屏 | `pages/index/index.vue loadHome()` → `appStore.applyConfig(home.config)` | `/v2/home` 带回的 config 子集先并进来，品牌位尽早拿到真值 |
| 首页下拉刷新 | `onPullDownRefresh` → `useBrand().refresh()` | 强制重拉，运营改完配置可立即验活 |
| 进入「关于我们」 | `pages/about/about.vue onLoad` → `refresh()` | 这一屏最直观，进去即刷新 |
| 登录页 | 登录开关为空时补拉一次 | 顺带刷新品牌 |

**并发去重**：`stores/app.ts` 用模块级 `inflight` 保证同一时刻只有一个 `/index/config` 在飞，
避免 App / 首页 / 登录页同时发起、后到的覆盖先到的。

**生效时机**：小程序没有服务端推送，后台改完名称后，用户**下一次冷启动**（或下拉刷新 / 进入关于页）生效，
不需要重新发版。这是平台物理边界，不是实现缺陷。

**缓存策略**：只缓存品牌三字段（key `brand_profile_cache`，带 `v` 版本号），
不缓存整份 config —— 登录开关 / tabbar / 版本号每次都必须拿最新值。

| 动态列表头像兜底首字 | `pages/feed/feed.vue` → `initialOf()` | `seal` |
| 活动页「活动均由 X 主办」 | `packages/pkg-user/pages/activity/activity.vue` | `name` |
| 主持人详情分享 | `packages/pkg-catalog/pages/staff-detail/staff-detail.vue` | `buildShare()` |
| 动态详情分享 | `packages/pkg-catalog/pages/feed-detail/feed-detail.vue` | `buildShare()` |
| 隐私弹窗协议名 | `components/privacy-popup/privacy-popup.vue` | `name` |
| 相册权限提示 | `composables/useChooseImage.ts` | `name` |
| H5 标签页标题 | `App.vue` → `syncDocumentTitle()` | `name` |

**唯一读取入口**：`useBrand()`（`newuniapp/src/composables/useBrand.ts`）。
页面 / 组件不允许直接 `import '@/constants/brand'`，也不允许自己读 `config.website`。

**首页 hero 左上角不设品牌位**（2026-11-19 移除）：首屏主图铺满到状态栏下，左上角只保留
系统胶囊，不再渲染 `brand-mark` / 站名 / 浅色牌面底衬。需要品牌曝光请用首屏 eyebrow、
「了解 X」、页脚锁定行或关于页，不要在主图上再叠一张 logo 牌。

## 6. 验证方式

### 6.1 自动化

```bash
cd newuniapp
npm run type-check      # 类型检查
npm run pages:check     # 路由校验
npm run header:check    # 头部一致性
npm run build:mp-weixin # 构建
npm run validate:dist   # 产物校验
```

### 6.2 残留硬编码自查

```bash
# 除兜底常量与注释外，不应再有品牌字面量
grep -rn "格林社\|GELIN\|Gelin" newuniapp/src --include=*.vue --include=*.ts
# 不应再有对旧常量的引用
grep -rn "BRAND_NAME\|BRAND_SEAL\|BRAND_EYEBROW\|BRAND_VERSION_PREFIX" newuniapp/src
```

### 6.3 真机走查（后台改一次，四类场景都要看）

1. **正常下发**：后台把「前台名称」改成 `格林社·测试`，LOGO 换一张明显的图 →
   杀进程重进 → 首页 hero、我的、关于页、活动页、隐私弹窗、相册权限提示、分享卡片全部跟着变。
2. **只配名称不配 LOGO**：清空前台LOGO → 所有品牌位回退成「格」字印章，不出现裂图。
3. **请求失败**：开发者工具切「离线」后杀进程重进 → 显示上次缓存的名称/图标（首次安装则显示兜底「格林社」+「格」字），
   控制台有一条 `index.config` 的 `api_error` 上报。
4. **图标 404**：把 LOGO 配成一个失效地址 → 全站回退印章字，不出现半屏裂图。

### 6.4 分享验证

- 首页右上角「转发」→ 卡片标题为后台名称；
- 主持人详情 / 动态详情「分享给朋友」→ 内容标题优先，缺失时为「品牌名 + 婚礼主持」，封面缺失时用品牌图标。

## 7. 已知边界

| 项 | 说明 |
| --- | --- |
| `manifest.json` 的 `name` / `description` | **构建期**元数据，uni-app 不支持运行时替换，改不了。它不参与小程序内任何展示位；微信里显示的 App 名称由微信公众平台后台设置，与代码无关。 |
| `pages.json` 的 `globalStyle.navigationBarTitleText` | 构建期兜底值（`婚庆服务`，中性词不是品牌名）。运行时由首页 `syncNavTitle()` 覆盖为后台名称。 |
| tabBar 文案 | `首页 / 动态 / 查档期 / 我的` 是页面名，不是品牌名，不参与品牌配置。 |
| 用户端生效延迟 | 冷启动或下拉刷新才更新，小程序无服务端推送。 |
| `uniapp/` 旧包 | 未改动。本次所有改动只落在 `newuniapp/`（及 `shared/`、`server/` 的必要契约）。 |
