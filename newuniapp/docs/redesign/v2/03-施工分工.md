## 1. 口径（三组统一，不许各写一套）

- **尺寸**：设计稿 390px 宽，系数 1.923，一律换算成 rpx。页面左右边距 42rpx，卡片圆角 32rpx，主按钮高 85–92rpx，tabbar 高 112rpx。**新写样式不许出现 px**。
- **颜色**：只用 `var(--c-*)`，禁止写十六进制。映射见 `00-工程底座.md`。
- **图鸟组件**：只用于弹层与表单原子件——`tn-popup` `tn-modal` `tn-calendar` `tn-picker` `tn-region-picker` `tn-subsection` `tn-checkbox` `tn-radio` `tn-input` `tn-action-sheet` `tn-empty` `tn-loading` `tn-swipe-action` `tn-search-box` `tn-rate` `tn-switch` `tn-notice-bar` `tn-count-down` `tn-steps`。**hero、卡片、底部操作栏、履约时间轴、压印印章、胶囊 tabbar 一律自绘**，不要用图鸟的 card/tabbar/steps 直接顶替设计稿。
- **金额**：只消费服务端字段（`amountDue` / `refundable_amount` / `pay_amount`），禁止前端做比例运算。定金+尾款 ≠ 总额时阻断支付并上报。
- **数据**：缺口字段一律 optional，缺了就"隐藏 / 改文案 / 给替代入口"，**禁止填假人数、假百分比、假评分、假"仅剩 N 档"**。
- **状态**：每屏必须实现 loading（骨架屏）/ empty / error（可重试）/ 无权限 四态，文案见 `02-交互状态与组件选型.md`。
- **协议勾选**：登录、预约确认、候补三处默认**未勾选**，未勾选时按钮不置灰、点按出红字。
- **暗黑模式**：不支持，不要写 `@media (prefers-color-scheme)`。
- **图标**：只用 `tn-icon`（`<tn-icon name="xxx">`），不自造图标字体，不引外链 SVG。

## 3. 完成判定（每屏都要过）

1. `npx uni build -p mp-weixin` 通过，无新增告警
2. 页面在 375 宽下与设计稿逐块对得上（截图自查：首屏、滚动中段、底部）
3. 四态齐全：骨架 / 空 / 错误可重试 / 无权限
4. 无 px、无硬编码色值、无假数据（搜索 `#[0-9a-fA-F]{3,6}` 与 `px` 自查）
5. 金额只来自服务端字段；协议默认未勾
6. 提交类操作有防重复（`useIdempotentSubmit` 或按钮 loading 锁）
