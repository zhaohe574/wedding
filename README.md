# 婚庆服务预约系统

小程序承载客户预约、支付、履约、问卷、售后和活动；管理后台负责 CRM、内容、财务、档期海报与月报；PC 端只展示品牌、案例、资讯和联系入口。

## 代码目录与开发范围

> 2026-11-11 起：**`uniapp/` 为旧包，已冻结；小程序只开发 `newuniapp/`。**

| 目录 | 定位 | 是否继续开发 |
|---|---|---|
| `newuniapp/` | 新版微信小程序（唯一开发目标） | ✅ 所有小程序需求 |
| `uniapp/` | 旧版微信小程序（legacy，已冻结） | ❌ 仅迁移对照；紧急线上修复需明确授权 |
| `admin/` | 运营后台 | ✅ 按需 |
| `pc/` | 品牌站 | ✅ 按需 |
| `server/` | ThinkPHP 后端 | ✅ 按需 |
| `shared/` | 跨端契约与工具 | ✅ 按需（生成文件勿手改） |

后续对话提到「小程序」「小程序端」「新小程序」而未指定目录时，默认指 `newuniapp/`。

## 快速开始

1. 在 `server` 执行 `composer install`，将站点根目录指向 `server/public`，访问 `/install/install.php` 安装空数据库。安装器使用 `.example.env` 生成本机 `.env`、随机密码盐和管理员账号。
2. 在 `admin`、`newuniapp`、`pc` 各自将 `.env.example` 作为本机 `.env` 的起点，填写后端域名，执行 `npm ci`。
3. 在后台配置微信小程序、服务号、微信支付、存储和验证码短信；小程序 `newuniapp/src/manifest.json` 的 `mp-weixin.appid` 必须与后台小程序配置一致。
4. 按[部署配置与验收](docs/部署配置与验收.md)准备独立本机测试数据库，再执行 `npm run qa:all`。
